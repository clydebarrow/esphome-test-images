Test images for the ESPHome `runtime_image` decoders. Generated by `make_images.py`:

```sh
python3 make_images.py .
```

| File | Format |
|---|---|
| `photo24.bmp` | 945x707 BMP, 24 bits per pixel |
| `photo8.bmp` | 945x707 BMP, 256-color palette |
| `mono.bmp` | 945x707 BMP, 1 bit per pixel |
| `dashboard.bmp` | 800x480 BMP, 24 bits per pixel, large flat areas |
| `photo.qoi` | 945x707 QOI |
| `dashboard.qoi` | 800x480 QOI, mostly runs |
